SurveyFlow – Online Survey & Poll Creator

A complete web-based survey management system developed as part of the RTRP Project 
for the Department of Computer Science & Engineering.

Features:
- User Authentication (Register & Login)
- Survey Creation with 6 question types (MCQ, Rating, Yes/No, Text, Paragraph, Dropdown)
- Survey Distribution via unique links, WhatsApp, Email, Twitter, LinkedIn, QR Code
- Response Collection with real-time storage
- Analytics & Reporting with charts and CSV export

Tech Stack: HTML, CSS, JavaScript (Vanilla)
